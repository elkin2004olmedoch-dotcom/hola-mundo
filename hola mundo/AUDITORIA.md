# Auditoría UX y Accesibilidad

## Proyecto
- Archivo principal: `index.html`
- Propósito: perfil estático del futbolista Moisés Caicedo

## Resumen rápido
El proyecto es una landing page sencilla y funcional. Tiene una base sólida como maqueta inicial, pero aún puede mejorarse en UX, accesibilidad visual y jerarquía de contenido.

## 1) UX
### Lo que funciona
- La idea es clara: el jugador es el foco principal.
- La estructura del contenido es fácil de seguir.
- La paleta oscura genera un estilo deportivo elegante.

### Qué mejorar
- La imagen debe ser más representativa del jugador real.
- La sección de información puede ganar más fuerza visual con mejor equilibrio entre texto e imagen.
- Falta un foco de acción más claro, por ejemplo un botón visual o una CTA.
- La identidad del perfil puede reforzarse con un mejor encabezado y composición.

## 2) Accesibilidad
### Lo que funciona
- El texto se mantiene legible en fondo oscuro.
- La imagen tiene un `alt` descriptivo.
- La estructura general es simple y entendible.

### Qué mejorar
- Mejorar contraste en algunos elementos secundarios.
- Mantener proporciones móviles más consistentes.
- Asegurar que botones y enlaces tengan enfoque claro en teclado.
- Usar más semántica HTML y menos elementos genéricos.

## 3) Calidad del código
### Lo que funciona
- El HTML es simple y fácil de mantener.
- El estilo está dentro del mismo archivo y no requiere dependencias.

### Qué mejorar
- Separar parte del CSS si el proyecto crece.
- Mejorar la semántica con `main`, `header`, `section`, `article` y etiquetas más claras.
- Definir mejores tamaños de tipografía y espaciado para mayor consistencia.

## 4) Recomendaciones prioritarias
1. Sustituir la imagen por una referencia más exacta del jugador.
2. Mejorar la jerarquía visual del encabezado y los datos del perfil.
3. Mejorar contraste y espaciado en mobile.
4. Añadir acciones visuales o CTA ligera.
5. Mantener una estructura HTML más semántica y clara.

## Conclusión
La página está bien como prototipo inicial, pero necesita un refinamiento visual y semántico para sentirse más profesional y más accesible.
